# CRM Clientes y Notas

Una aplicación web sencilla para gestión de relaciones con clientes (CRM) que permite administrar información de clientes y sus notas asociadas.

## 🚀 Demo

**URL de la aplicación:** [https://crm-clientes-notas-36lk2hooh-luisernestosalas-2775s-projects.vercel.app](https://crm-clientes-notas-36lk2hooh-luisernestosalas-2775s-projects.vercel.app)

## 📋 Características

- ✅ Gestión completa de clientes (crear, leer, actualizar, eliminar)
- ✅ Sistema de notas asociadas a cada cliente
- ✅ Interfaz intuitiva y responsive
- ✅ Almacenamiento local de datos
- ✅ Búsqueda y filtrado de clientes
- ✅ Diseño moderno y limpio

## 🛠️ Tecnologías

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Almacenamiento:** LocalStorage del navegador
- **Despliegue:** Vercel
