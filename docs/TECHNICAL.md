# Documentación Técnica - CRM Clientes y Notas

## Información General
- **Aplicación**: CRM con clientes y notas
- **Stack tecnológico**: HTML + JavaScript
- **Repositorio**: https://github.com/luisernestosalas/crm-clientes-notas
- **URL de producción**: https://crm-clientes-notas-36lk2hooh-luisernestosalas-2775s-projects.vercel.app

## Descripción del Proyecto
Sistema de gestión de relaciones con clientes (CRM) desarrollado con tecnologías web frontend básicas, permitiendo la administración de clientes y sus respectivas notas o comentarios.

## Arquitectura Técnica

### Frontend
- **HTML**: Estructura de la interfaz de usuario
- **JavaScript**: Lógica de la aplicación y manipulación del DOM
- **Almacenamiento**: LocalStorage/SessionStorage (presumible)

### Despliegue
- **Plataforma**: Vercel
- **Tipo**: Aplicación estática frontend

## Funcionalidades Principales
- Gestión de clientes (CRUD)
- Sistema de notas asociadas a clientes
- Interfaz web responsive
- Almacenamiento local de datos
